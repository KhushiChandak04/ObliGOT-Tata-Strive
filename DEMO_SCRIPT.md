# Demo Script

1. Open the dashboard and explain that any preloaded records are illustrative.
2. Open the partner directory and review a sample partner profile.
3. Review the pipeline, agreements, projects, finance, reports, and action center pages; distinguish connected functionality from scaffold screens.
4. Demonstrate `GET /api/health` and inspect `/docs` to show the API contract.
5. Demonstrate project create → fetch → update → delete through Swagger or the API tests.
6. Upload a sample CSV/XLSX or send JSON rows to `/api/import/preview`; show validation issues and confirm `committed: false`.
7. Explain that live Firestore persistence requires Firebase project configuration and credentials. Do not describe demo-memory records as persistent.
